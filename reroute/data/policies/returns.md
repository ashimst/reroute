**Retail Flow – Returns Policy for AI Order Exception Agent**  
Effective: 2026-01-01 | Policy ID: RET-POL-1.0

**RET-01** This policy applies to all orders placed on retailflow.com.

**RET-02** The standard return window is 30 calendar days from the delivery date confirmed by the carrier.

**RET-03** A standard return is eligible if: (a) the request is within RET-02; (b) the item is not listed in RET-07; (c) the item meets RET-06; and (d) the customer provides the RET-05 information.

**RET-04** The customer must initiate the return through the AI agent or the Retail Flow web portal.

**RET-05** Required information for any return: order number, item SKU, reason code, and photo evidence for damaged, incorrect, or missing items. For standard returns, no photo is required.

**RET-06** Product condition for standard returns: unused, unwashed, undamaged, with all original accessories, manuals, and packaging. Apparel must have original tags attached. Electronics must have an unbroken factory seal unless the item is defective.

**RET-07** Non-returnable categories: gift cards, digital downloads, perishable food, live plants, personalized or custom-made items, hazardous materials, opened intimate apparel, and items marked “final sale” or “non-returnable” on the product page.

**RET-08** If an item is in RET-07, the AI agent must deny the return.

**RET-09** Damaged on arrival: the customer must report within 7 calendar days of delivery and provide a photo of the damage and the shipping box. The AI agent must approve a replacement or full refund.

**RET-10** If a damage report is received after 7 calendar days, the AI agent must deny the return unless RET-20 applies.

**RET-11** Incorrect item received: the customer must report within 14 calendar days of delivery and provide a photo of the item received and the packing slip. The AI agent must approve a replacement or full refund.

**RET-12** Missing item: the customer must report within 14 calendar days of delivery and provide a photo of the packing slip and the box contents. The AI agent must approve a replacement or full refund if the carrier weight record confirms the missing item.

**RET-13** If a missing item claim is received after 14 calendar days, the AI agent must deny the return unless RET-20 applies.

**RET-14** Return shipping costs: the customer pays for standard returns. Retail Flow provides a prepaid label for damaged, incorrect, or missing items.

**RET-15** Refund method: original payment method within 5 business days after the returned item passes inspection. The AI agent must initiate the refund.

**RET-16** If the customer requests an exchange, the AI agent must process it if the requested SKU is in stock.

**RET-17** The AI agent must escalate to a human agent if the refund amount is greater than $500.

**RET-18** The AI agent must escalate to a human agent if the customer has more than 3 returns in the previous 90 calendar days.

**RET-19** The AI agent must escalate to a human agent if the order has a fraud flag or the shipping address does not match the billing address.

**RET-20** The AI agent must escalate to a human agent if the customer disputes the AI decision or requests an exception.

**RET-21** The AI agent must escalate to a human agent if required evidence is missing or unclear.

**RET-22** The AI agent must escalate to a human agent if the item is a regulated good not listed in RET-07.

**RET-23** The AI agent must not override RET-17 through RET-22.

**RET-24** The AI agent must log every decision with the applicable rule ID.

**RET-25** This policy replaces all prior returns policies for AI-handled exceptions at Retail Flow.
