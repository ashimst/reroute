⚡ REROUTE • Dual-Process Retail Exception Routing Engine

Autonomous e-commerce exception resolution engine designed with Noesis Frameworks architecture. Combines fast deterministic reflex triaging (System 1) with deliberative LLM reasoning (System 2) across 99,441 real Olist transactions.

Core Architecture & Pipeline

  • OpenJEV Probabilistic Routing: Categorizes customer intent (Returns, Delivery, Payment) with confidence scoring.
  • LangGraph State Machine: Deterministic DAG routing through compliance rules and escalation policies.
  • Policy RAG (FAISS + MiniLM): Millisecond semantic retrieval against return windows, carrier SLA, and refund regulations.
  • Cactus Needle Tool Execution: High-precision deterministic calculation of eligibility, refund amounts, and delivery timelines.
  • Groq LLM Deliberation: Zero-shot fallback reasoning when edge cases breach confidence thresholds.
