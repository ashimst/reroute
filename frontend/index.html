NOESIS FRAMEWORKS • OPEN-SOURCE REFERENCE ARCHITECTURE

Autonomous Retail Exception Routing. Deterministic First. LLM Second.

Stop letting generative AI hallucinate refund math. REROUTE resolves 80%+ of returns, delivery claims, and SLA exceptions in <50ms at $0 LLM cost using deterministic tool execution (System 1)—falling back to Groq LLM reasoning (System 2) only on ambiguous edge cases.

Dual-Process System Architecture

  • OpenJEV Intent Classification: Centroid vector classifier triaging customer complaints into Returns, Delivery, or Payment with calibrated confidence scores.
  • LangGraph Deterministic StateGraph: Directs confident claims straight through deterministic validation DAG nodes without expensive LLM token inference.
  • Policy RAG (FAISS + MiniLM): Millisecond semantic retrieval against Brazilian CDC statutory consumer law, freight delay policies, and merchant regulations.
  • Cactus Needle Tool Execution: High-precision deterministic calculation of delivery dates, SLA breaches, and statutory refund amounts ($0 Hallucinations).
  • System 2 Groq Deliberation: Activates Qwen-32B on Groq LPU only when confidence breaches the threshold or multi-intent claims require legal deliberation.
  • Pluggable Adapter Pattern (BaseCommerceAdapter): Swap the bundled 99,441 Olist dataset for Shopify, BigCommerce, or internal PostgreSQL in under 50 lines of Python.
